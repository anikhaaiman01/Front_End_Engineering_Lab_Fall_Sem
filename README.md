# Front End Engineering Lab – Fall Semester

## About

This repository contains lab exercises and practical assignments completed as part of the Front End Engineering Lab course.

## Technologies Used

* HTML5
* CSS3

## Lab Exercises

* **Lab 1:** Personal Profile Webpage using Semantic HTML5 and CSS Layouts and Trying Out Styling Of Any Website With Simple Features And Minimal CSS

## Objective

To learn the fundamentals of front-end web development by creating structured webpages and practising HTML and CSS.
